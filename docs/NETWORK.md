# Интернет-переписка Mura 1.1

Чат реализован на **Android и iOS**. Общий протокол описан в [документации сервера](../server/README.md). Совместимость Apple CryptoKit ↔ Bouncy Castle проверена на настоящих HPKE-конвертах и через публичный HTTPS-сервер.

Android: `core:domain/ChatCrypto.kt`, `RelayClient.kt`; хранение и синхронизация — `core:data/NetworkRepository.kt`. iOS: `ChatCrypto.swift`, `RelayClient.swift`, `NetworkState.swift`.

Код `MURA-CONTACT1:` содержит HTTPS-адрес и два открытых ключа. ID — SHA-256(Ed25519 public || X25519 public). Оба пользователя добавляют друг друга; ключи закреплены в зашифрованной локальной записи. Код безопасности сверяется непосредственно с владельцем контакта.

**HPKE Auth / RFC 9180**: X25519 + HKDF-SHA256 + ChaCha20-Poly1305. Android — lightweight API Bouncy Castle **1.86**, iOS — Apple CryptoKit. HTTP-запросы и квитанции подписываются отдельным Ed25519-ключом.

Исходящий конверт шифруется и сохраняется до запроса. UUID сохраняется при повторе. Сервер идемпотентно принимает сообщение; статус становится «Отправлено». Входящее сообщение и отметка дедупликации сохраняются одной транзакцией перед ACK. «Доставлено» требует проверки подписи квитанции ключом получателя и хеша точного конверта.

Android: идентичность, сетевые настройки, список принятых UUID, коды контактов и очередь зашифрованы AES-GCM ключом Keystore. Миграция Room 1 → 2 сохраняет историю, добавляет nullable peerCode / envelope, delivery с default 'local' и таблицу network. iOS использует локальный Keychain-ключ. Резервное копирование отключено.

Синхронизация примерно раз в 4 секунды при открытом и разблокированном приложении. Push и фоновая доставка отсутствуют. Очередь сервера — до 7 дней, дедупликация — 8 дней. Старые локальные диалоги автоматически в сеть не отправляются.

Удаление контакта отзывает разрешение; офлайн-отзыв сохраняется до синхронизации. Полное удаление меняет идентичность и по возможности удаляет серверную регистрацию. Без связи прежние серверные конверты истекают по TTL. Удаление сообщения не удаляет копию у собеседника.

Это не Double Ratchet: forward secrecy при компрометации долговременного ключа получателя, восстановление аккаунта, независимый аудит и постоянный хостинг пока отсутствуют. Сервер и HTTPS-прокси видят маршрутизационные метаданные.

Источники: [Bouncy Castle HPKE](https://downloads.bouncycastle.org/java/docs/bcprov-jdk18on-javadoc/org/bouncycastle/crypto/hpke/HPKE.html), [Apple HPKE](https://developer.apple.com/documentation/cryptokit/hpke), [RFC 9180](https://www.rfc-editor.org/rfc/rfc9180).
