**Mura 1.1 — установка на Android**

Понадобится Android 8.0 или новее. Для установки APK компьютер не нужен.

1. Открой на Android [страницу скачивания](https://defense-arthritis-maritime-salvador.trycloudflare.com/download).
2. Нажми **Скачать для Android** и дождись загрузки файла `Mura-1.1.0.apk`.
3. Открой файл из уведомления о загрузке или папки «Загрузки».
4. Если Android попросит разрешение, открой настройки установки для браузера или файлового менеджера и включи **«Разрешить установку из этого источника»**. Название пункта зависит от телефона. Вернись к APK и нажми **Установить**. [Справка Google](https://support.google.com/pixelphone/answer/7391672).
5. Открой Mura.

APK также можно переслать файлом: `artifacts/Mura-1.1.0.apk`. Это установщик для Android. Для iPhone используется отдельная iOS-сборка.

**Переписка с Android или iPhone**

1. На обоих устройствах открой Mura 1.1 и проверь один адрес в **Настройки → Переписка через интернет**.
2. Открой **Чаты → Мой код** и передай собеседнику весь код или покажи QR.
3. Собеседник открывает **Новый диалог**, указывает имя, вставляет твой код или сканирует QR и нажимает **Добавить контакт**.
4. Теперь собеседник передаёт свой код, а ты добавляешь его. **Каждый добавляет код другого**.
5. Открой диалог, введи текст и нажми самолётик. Пароль для чата не требуется.

В диалоге можно открыть «Код безопасности» и сверить его с «Мой код безопасности» на телефоне собеседника.

«В очереди» — сообщение сохранено и ожидает отправки. «Отправлено» — принято сервером. «Доставлено» — сохранено приложением собеседника; прочтение человеком этот статус не подтверждает.

Сообщения приходят при **открытой и разблокированной Mura**. Уведомлений пока нет. Сервер хранит неполученные сообщения до 7 дней. Mac владельца должен быть включён, без сна и с интернетом. Страница скачивания использует тот же временный адрес; после перезапуска туннеля он может измениться.

**Шифратор и история**

В **Шифратор → Защита** можно зашифровать текст паролем от 4 символов, например `6899`. Передай результат `MURA1:` и сообщи пароль отдельно. Получатель выбирает «Расшифровать» и вводит тот же пароль. Этот режим работает без сервера. В режиме «Кодирование» текст превращается в цифры без пароля; любой владелец кода может вернуть текст.

В «Настройках» доступны языки RU / KZ / EN, тема и биометрическая блокировка. По умолчанию история и сообщения старше 30 дней очищаются, кроме избранного. Для бессрочного хранения выбери **Очистка истории → Никогда**.

**Обновление**

Следующие release-версии с той же подписью устанавливаются поверх этой, сохраняя данные. У APK нет недельного срока подписи Personal Team, который используется в текущей iOS-сборке.

Если уже установлена старая тестовая debug-версия Mura, её подпись отличается: обновление release-APK будет отклонено. Сначала сохрани важные тексты; удаление приложения стирает локальные данные и требует нового обмена кодами. Подготовленный debug-APK можно использовать для обновления прежней тестовой установки с её исходной подписью.

Удаление сообщения очищает его на твоём телефоне. **Удалить историю и профиль** также меняет ключи: после этого нужно снова обменяться кодами. Восстановления истории из облака пока нет.
