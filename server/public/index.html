mura

Зашифрованная переписка между Android и iPhone. Текст в цифрах, отдельные сообщения с паролем и личная история.

Скачать для Android

Версия 1.1.0 · Android 8.0 и новее · SHA-256

  1. Открой эту страницу на Android и скачай APK.
  2. Открой скачанный файл. Если Android попросит, разреши установку приложений для браузера или файлового менеджера, через который открываешь файл.
  3. Нажми «Установить», затем открой Mura.
  4. В приложении открой «Чаты → Мой код». Обменяйтесь кодами: каждый добавляет код другого через «Новый диалог».

Пароль для чата не нужен. В разделе «Шифратор → Защита» можно отдельно зашифровать текст паролем от 4 символов.

Для переписки на iPhone нужна установленная Mura 1.1. APK предназначен для Android. Сообщения приходят при открытой и разблокированной Mura; уведомлений пока нет. Сервер работает на Mac владельца и доступен, пока компьютер включён, не спит и подключён к интернету. Адрес страницы временный и может измениться после перезапуска туннеля.
