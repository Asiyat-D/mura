# Проверки Mura iOS 1.1

Дата: 19 октября 2026 года. Xcode 27.1, Swift 6, iOS SDK 27.1; iOS 17+, Swift Package для macOS 14+.

## Выполнено

| Проверка | Результат |
|---|---|
| Swift XCTest: ядро, HPKE и транспорт | **13 / 13**, 0 failures |
| Полный диапазон Unicode scalar values | Точное сравнение UTF-8-байтов пройдено |
| Пароль `6899` | Шифрование / расшифрование пройдено; 3 символа отклоняются |
| Старый формат Android → iOS | Цифровой код и `MURA1:` совместимы |
| iOS → Android/JVM с паролем `6899` | Реальные Android `DecimalCodec` / `PasswordCipher` проверили Swift-результат |
| HPKE Auth | Круговой обмен, случайность, неверный получатель / отправитель, подмена ciphertext и AAD |
| Квитанции доставки | Чужая подпись и квитанция от другого сообщения отклоняются |
| Python-сервер | **4 / 4**: подмена ID, replay, взаимное добавление, идемпотентность, поддельная квитанция, права доступа, удаление, TTL и фоновая уборка |
| Реальный публичный HTTPS-сервер | Двусторонний обмен двух независимых Swift-клиентов и подписанные квитанции пройдены |
| UI на iPhone 16 Pro / iOS 18.7.8 | **1 / 1**, 98,692 с: добавление контакта, приём, отправка, «Доставлено», холодный запуск, Face ID, сохранность обоих сообщений, удаление тестового контакта |
| Финальные Release-сборки arm64: Simulator и iPhone unsigned | Обе **BUILD SUCCEEDED**; симуляторный runtime не запускался |
| Подпись Apple Development | `codesign --verify --deep --strict`; профиль включает подключённый iPhone |
| Android: изменение короткого пароля | **9 / 9** JVM-тестов; assembleDebug и lintDebug пройдены |

UI-тест запускает приложение Mura и отдельную тестовую идентичность в тестовом процессе на iPhone; обе используют публичный HTTPS-адрес. Это проверка двух клиентов, а не заявление об испытании на двух физических iPhone. Второй телефон для этой проверки не подключался.

В ходе проверки исправлены возврат интерфейса после Face ID и безопасное обновление исполняемого файла туннеля. Последний UI-прогон завершился `TEST SUCCEEDED`; ранние диагностические прогоны не считаются успешными.

Сводки и логи ядра / сервера находятся в `artifacts/ios-reports/` и `mura-ios-reports.zip`. Исходные `.xcresult` хранятся локально и исключены из распространяемого архива отчётов. Интерфейс не проверялся в симуляторе: iOS Simulator Runtime отсутствует.

## Пределы проверки

- Камера, сканирование QR с физического носителя, Share Sheet, импорт от внешнего провайдера, VoiceOver, крупный шрифт и весь набор поворотов отдельно не прогонялись.
- Восстановление после удаления приложения / потери Keychain-ключа не поддерживается. Полный аудит криптографии и протокола не выполнялся.
- Push/APNs и фоновая доставка отсутствуют. Сообщения принимаются при открытой и разблокированной Mura; очередь на сервере живёт до 7 дней.
- Текущий Quick Tunnel зависит от работающего Mac и может менять адрес после перезапуска. Настройки сна не изменялись.
- Development-подпись текущего iPhone действует до 26 октября 2026 года. Для установки на другой физический iPhone его нужно добавить в provisioning profile.

Сервер, протокол и ограничения HPKE описаны в [server/README.md](../../server/README.md).
